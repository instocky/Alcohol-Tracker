# Brief: Alcohol Tracker — Chrome Extension MVP (v0.1)

> Версия артефакта: **v0.1** — фиксирует UX и data-правила после design review и итераций над `proposed.html`. Базовый бриф ниже дополнен принятыми решениями и беклогом.

---

## Goal

Локальное Chrome-расширение для учёта употреблённого алкоголя. Базовой единицей хранения — **граммы чистого этилового спирта**.

Гипотеза для проверки:

> Удобнее ли вести учёт через недельный календарь с быстрым добавлением стандартных порций, чем через обычную форму «добавить сегодня».

---

## Архитектура

- **MV3**, TypeScript, Vite, vanilla HTML/CSS/TS.
- **chrome.storage.local** — единственное хранилище. Никакого backend / auth / sync / telemetry.
- Событийная модель: каждое нажатие `+` = отдельный event. Агрегация на render.

**Хранение vs derived:**

- Храним — `pure_alcohol_g` (снапшот значения на момент записи).
- Derived на UI — `standard_drinks = pure_alcohol_g / 14` (1 US SD = 14 г спирта).
- Derived никогда не сохраняется — пересчитывается на render.

---

## Расчёт

```text
pure_alcohol_g = volume_ml × (ABV / 100) × 0.789
```

Примеры (фиксированы для дефолтных пресетов):

| Напиток | Объём  | ABV | Граммы спирта |
| ------- | ------ | --- | ------------- |
| Водка   | 50 мл  | 40% | 15.78 г       |
| Вино    | 150 мл | 12% | 14.20 г       |
| Вино    | 100 мл | 12% | 9.47 г        |
| Пиво    | 0,45 л | 5%  | 17.75 г       |
| Пиво    | 0,33 л | 5%  | 13.02 г       |

---

## Data model

```json
{
  "id": "uuid",
  "date": "2026-10-02",
  "type": "vodka",
  "volume_ml": 50,
  "abv": 40,
  "pure_alcohol_g": 15.78,
  "created_at": "2026-10-02T09:30:00"
```

**Важно:** `pure_alcohol_g` снапшотится в запись, чтобы исторические записи не зависели от изменений ABV/объёма в пресетах.

## UX — экраны

Три экрана, переключение через bottom nav:

1. **Неделя** (по умолчанию) — календарь + день + quick-add + total
2. **Статистика** — week / month / year, карточки метрик
3. **Настройки** — пресеты напитков, история, экспорт CSV, info-полоса о приватности

---

## UX — экран «Неделя»

### Шапка

Центрированный range из 5 дней:

```text
30 сен – 4 окт 2026
```

Стрелки `‹ / ›` находятся **на уровне календаря**, а не в шапке. Шаг стрелки = 1 день.

### Календарь (5 ячеек)

```text
[‹]   ср   чт   пт   сб   вс    [›]
       30    1    2    3    4
```

Центр окна = выбранный день. Сегодня может выйти за пределы окна при навигации.

**Три индикатора, разведены по форме/положению:**

| Индикатор                       | Семантика               |
| ------------------------------- | ----------------------- |
| Filled bg (чёрный)              | Выбранный день          |
| Emerald ring (1.5px outline)    | Сегодня                 |
| Точка под числом (4px, emerald) | В этот день есть записи |

Когда «сегодня» = «выбранный» — оба индикатора видны одновременно (ring + точка).

### Day title

```text
Четверг, 2 октября                        [сегодня]
```

Tag «сегодня» показывается только если `selected === today`. Иначе скрыт.

### Quick-add (card)

Каждый напиток в строке: **имя + градус** сверху, **объём** под.

```text
🥃  Водка · 40%                                  [ + ]
    50 мл

🍷  Вино · 12%                       [150] [100]  [ + ]
                                       мл

🍺  Пиво · 5%                       [0,45] [0,33] [ + ]
                                       л
```

**Правила тогглов:**

- Водка — единственный объём 50 мл, тоггл не нужен.
- Вино — тоггл между 150 и 100 мл. По умолчанию 150.
- Пиво — тоггл между 0,45 и 0,33 л. По умолчанию 0,45.
- Активный сегмент визуально выделен (filled bg внутри pill).
- `+` всегда добавляет **активный** объём — переключение объёма обновляет `data-key` на `+` кнопке.

### Debounce

`+` имеет **debounce 300 мс** — второй клик в окне игнорируется. Защита от двойного тапа и случайного добавления двух порций.

### Список записей дня

```text
🥃  Водка 50 мл  × 2 · 40%            31.6 г    [−]
🍺  Пиво 0,45 л  × 1 · 5%             17.8 г    [−]
```

Каждая запись — отдельный event. `−` справа удаляет запись.

### Total

```text
ИТОГО СПИРТА                            49.3 г
≈ 3,5 стандартных дринка
```

- Слева: label + sub (стандартные дринки, склонение по правилам русского).
- Справа: главная цифра в граммах (1 десятичный).
- Хранится граммы, дринки = derived.

### Empty state

```text
Сегодня чисто. Хорошего дня.       — если selected = today
Этот день без записей.              — иначе
```

### Undo

5-секундный toast после `+` и `−`:

```text
[Запись добавлена / удалена]              [Отменить]
```

Undo возвращает запись в тот день, откуда удалили (если удалили не из selected дня).

**Удалено из MVP:** «Очистить все данные» — случайный тап необратимо теряет историю. Вместо wipe — Экспорт CSV как мягкий «soft reset».

## Правила данных

- Каждое нажатие `+` = отдельный event. Физически не объединять в БД.
- Агрегация на render:

```text
events → filter by date/range → aggregate → statistics
```

- `date` — **local date** (YYYY-MM-DD), без времени.
- Будущие даты — можно (backfill и «запись за вчера» поддерживаются).

---

## Constraints (что не делать в MVP)

- Backend, auth, облачная синхронизация.
- БД (только chrome.storage).
- AI / LLM, analytics, telemetry.
- Multi-user.
- Dark mode (опционально позже).

---

## Backlog (не v0.1, но обсуждалось)

- Полный undo-history (multi-undo) — сейчас только последнее действие через toast.
- Hard-reset через hidden combo (7 тапов на лого) — если понадобится.
- Hotkeys для quick-add.
- Bulk-add / copy-from-yesterday.
- Тёмная тема.
- Notifications / reminders.
- WHO 20 г/день как порог с цветовым сигналом (вместо info-strip).
- Dark mode toggle.

---

## Anti-patterns (что не делать)

- Не показывать «рекорд» / «перебор» / «тревожный уровень» без opt-in. Тон — нейтрально-аналитический.
- Не использовать красный цвет для shame-индикации. Warn = мягкий amber.
- Не объединять `+` в physical event merge. Хранить как 1 порция = 1 event.
- Не показывать emoji-иконки без fallback (платформо-зависимый рендер). Если важна консистентность — SVG-иконки одного веса.
- Не добавлять «Очистить все данные» в UI (случайный тап = потеря).

---

## Done when (v0.1)

1. Открыл расширение — увидел текущий день, выбран по умолчанию.
2. Виден 5-дневный календарь с индикаторами (сегодня ring, есть записи точка, выбран fill).
3. `‹ / ›` листают по 1 дню.
4. Quick-add: `+` добавляет порцию выбранного объёма; тогглы переключают объём.
5. Двойной клик `+` за 300 мс = одна запись (debounce).
6. Удаление записи → toast «Отменить» на 5 секунд.
7. Total: граммы + derived дринки.
8. Empty state динамический по `selected`.
9. Статистика — week / month / year с 4 карточками.
10. Settings: пресеты, история (последние 20), экспорт CSV, info-полоса.
11. Перезапустил Chrome — все данные на месте.
12. Закрыл popup / открыл — состояние восстановлено.
